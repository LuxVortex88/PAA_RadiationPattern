# Phased Array Antenna Radiation Pattern

This Python script simulates the radiation pattern of a basic uniform linear phased array antenna.

### Features

- 8 isotropic elements
- Uniform spacing of 0.5 wavelengths
- No beam steering (broadside pattern)
- Visualizes the array’s radiation pattern in 2D

### Requirements

- Python 3.x
- `numpy`
- `matplotlib`

### Usage

Run the script:

```bash
python phased_array.py
